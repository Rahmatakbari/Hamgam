# فروشگاه هم‌گام — نسخهٔ موبایل (۳ فایل)

یک سیستم مدیریت فروشگاه **آفلاین، بدون نصب و بدون ساخت (build)** که فقط با سه فایل کار می‌کند.
مخصوص موبایل (موبایل‌اول) و مناسب دکان‌های کوچک و متوسط در افغانستان و ایران.

## فایل‌ها
| فایل | کاربرد |
|------|--------|
| `index.html` | اسکلت صفحه و منوی پایین |
| `style.css`  | ظاهر، رنگ‌ها، حالت تاریک، چاپ فاکتور |
| `app.js`     | تمام منطق برنامه (بدون هیچ کتابخانه‌ای) |

> هر سه فایل **حتماً در یک پوشه** باشند.

## نصب روی گوشی (بدون اینترنت)
1. سه فایل را در یک پوشه در حافظهٔ گوشی بگذارید.
2. روی `index.html` ضربه بزنید تا در مرورگر باز شود.
3. در **QuickEdit**: همان پوشه را باز کنید و روی `index.html` دکمهٔ Preview را بزنید.
4. برای دسترسی سریع، برنامه را به صفحهٔ اصلی (Add to Home Screen) اضافه کنید.

## ویژگی‌ها
- **فروش سریع**: جست‌وجوی کالا، سبد خرید، تخفیف، پرداخت نقد/نسیه، چاپ و ارسال فاکتور.
- **کالا و انبار**: ثبت/ویرایش کالا، هشدار کمبود موجودی، ارزش انبار.
- **مشتریان و حساب**: ماندهٔ طلب، تاریخچه، دریافت پول، **یادآوری در واتساپ** (با شمارهٔ بین‌المللی افغانستان/ایران).
- **گزارش‌ها**: فروش، سود، نقد، نسیه، پرفروش‌ترین‌ها و بدهکاران (امروز / ۷ روز / ۳۰ روز / همه).
- **مصارف**: ثبت خرج دکان و محاسبهٔ سود خالص.
- **پشتیبان‌گیری / بازیابی**: خروجی JSON برای انتقال بین گوشی‌ها.
- **تاریخ شمسی** (جلالی) با نام‌های ماه‌های افغانستان یا ایران.
- **حالت تاریک** و رابط کاملاً راست‌به‌چپ (RTL).

## نکات مهم
- داده‌ها **فقط داخل همین گوشی** (حافظهٔ مرورگر / `localStorage`) ذخیره می‌شود.
- هر چند وقت یک‌بار **«پشتیبان‌گیری»** کنید و فایل را جای امن نگه دارید؛ پاک کردن حافظهٔ مرورگر داده‌ها را حذف می‌کند.
- این نسخه کاملاً **مستقل** از پروژهٔ React/PWA است و روی هم تأثیری ندارند.
